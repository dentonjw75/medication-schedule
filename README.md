# Medication Schedule PWA

Privacy-safe starter for GitHub Pages. This repository contains **sample data only**. Real patient schedules entered in the app are stored locally in that browser/device.

## Publish with GitHub Pages

1. Open the `medication-schedule` repository on GitHub.
2. Upload `index.html`, `manifest.webmanifest`, `sw.js`, and the entire `icons` folder to the repository root.
3. Commit the upload to `main`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. When GitHub shows the Pages URL, open it in Safari on iPhone.
8. Tap **Share → Add to Home Screen**.

## Privacy

No real patient data is included in these source files. Data you enter is saved in browser local storage on the device and is not automatically uploaded to GitHub.

Backup exports can contain real patient information, so treat those JSON files as sensitive.
